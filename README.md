Battle Arena | C# Console Game

Project Overview
Battle Arena is a turn-based console game developed using C# and .NET. I created this project to apply and strengthen my understanding of fundamental programming concepts through a practical, interactive application.

Players battle against a Goblin, strategically choosing whether to attack, heal, or defend until either the player or enemy is defeated.

Game Features
Attack: Deal randomized damage to the enemy.
Heal: Recover health without exceeding the maximum of 100 HP.
Defend: Reduce incoming damage using a randomized shield value.
Turn-Based Combat: Continue battling until either character reaches zero health.
Input Validation: Handle invalid player selections without advancing the enemy's turn.
Victory and Defeat: Display the outcome when the battle ends.

Programming Concepts Demonstrated
C# variables and data types
Conditional statements (if, else if, else)
while loops
Random number generation using Random.Next()
User input using Console.ReadLine()
String interpolation
Arithmetic operations and health calculations
Basic debugging and logical problem-solving

How to Run
Install the .NET SDK.
Download or clone this repository.
Open a terminal in the project folder.
Run the following command:
dotnet run
