
# Battle Arena | C# Console Game

## Project Overview

Battle Arena is a turn-based console game developed using C# and .NET. I created this project to apply and strengthen my understanding of fundamental programming concepts through a practical, interactive application.

Players battle against a Goblin, choosing whether to attack, heal, or defend until either the player or enemy is defeated.

## Game Features

- **Attack:** Deal randomized damage to the enemy.
- **Heal:** Recover health without exceeding 100 HP.
- **Defend:** Reduce incoming damage using a randomized shield value.
- **Turn-Based Combat:** Battle until either character reaches zero health.
- **Input Validation:** Prevent invalid selections from advancing the enemy's turn.
- **Victory and Defeat:** Display the final battle outcome.

## Programming Concepts Demonstrated

- C# variables and data types
- Conditional statements (`if`, `else if`, `else`)
- `while` loops
- Random number generation with `Random.Next()`
- User input with `Console.ReadLine()`
- String interpolation
- Arithmetic operations and health calculations
- Debugging and problem-solving

## How to Run

1. Install the .NET SDK.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
dotnet run
```
